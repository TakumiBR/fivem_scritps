# StrykerPro reference notes

A V0.2.4 foi calibrada usando o resource `Stretcher-1.0.5` fornecido pelo usuario apenas como referencia de comportamento.

Observacoes reproduzidas no FiveEMS por implementacao propria:

- `strykerpro` e tratado como `CVehicle`.
- Conducao do modelo exige offset aproximado `(-0.05, 1.375, -0.345)` e rotacao relativa `(180, 180, 180)`.
- O modelo usa extras 1/2 como geometrias operacionais mutuamente exclusivas.
- Equipamentos conhecidos: prancha=3, monitor=5, bolsa vermelha=6, bolsa azul=7, cabeceira=11/12.
- A orientacao inicial do modelo usa heading do operador - 90 graus.

Os assets e o codigo do resource de referencia nao foram incorporados ao FiveEMS.
